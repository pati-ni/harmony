# Package index

## All functions

- [`RunHarmony()`](https://pati-ni.github.io/harmony/reference/RunHarmony.md)
  : Generic function that runs the harmony algorithm on single-cell
  genomics cell embeddings.
- [`RunHarmony(`*`<Seurat>`*`)`](https://pati-ni.github.io/harmony/reference/RunHarmony.Seurat.md)
  : Applies harmony on a Seurat object cell embedding.
- [`RunHarmony(`*`<SingleCellExperiment>`*`)`](https://pati-ni.github.io/harmony/reference/RunHarmony.SingleCellExperiment.md)
  : Applies harmony on PCA cell embeddings of a SingleCellExperiment.
- [`RunHarmony(`*`<default>`*`)`](https://pati-ni.github.io/harmony/reference/RunHarmony.default.md)
  : This is the primary harmony interface.
- [`cell_lines`](https://pati-ni.github.io/harmony/reference/cell_lines.md)
  : List of metadata table and scaled PCs matrix
- [`cell_lines_small`](https://pati-ni.github.io/harmony/reference/cell_lines_small.md)
  : Same as cell_lines but smaller (300 cells).
- [`-package`](https://pati-ni.github.io/harmony/reference/harmony.md)
  [`harmony`](https://pati-ni.github.io/harmony/reference/harmony.md) :
  Harmony: fast, accurate, and robust single cell integration.
- [`harmony_options()`](https://pati-ni.github.io/harmony/reference/harmony_options.md)
  : Set advanced parameters for RunHarmony
- [`pbmc.ctrl`](https://pati-ni.github.io/harmony/reference/pbmc.ctrl.md)
  : Gene expression data of control PBMC from Kang et al. 2017. This
  contains a sample of 1000 cells from that condition and is used for
  the Seurat Vignette.
- [`pbmc.stim`](https://pati-ni.github.io/harmony/reference/pbmc.stim.md)
  : Gene expression data of stimulated PBMC from Kang et al. 2017. This
  contains a sample of 1000 cells from that condition and is used for
  the Seurat Vignette.
